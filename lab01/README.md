# Labo 1

## Instructions d'exécution

### Java

À partir de la racine du dépôt, changez de répertoire au dossier Java.
```bash
cd newmath_java
```

Pour exécuter le programme.
```bash
./bin/run
```

Pour exécuter les tests.
```bash
./bin/test
```

### Elixir

À partir de la racine du dépôt, changez de répertoire au dossier Elixir.
```bash
cd newmath_ex
```

Pour exécuter le programme.
```bash
./bin/run
```

Pour exécuter les tests.
```bash
./bin/test
```
